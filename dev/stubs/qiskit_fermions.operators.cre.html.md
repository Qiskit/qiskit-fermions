# cre

### cre(mode)

Constructs a creation action on the fermionic mode at `mode`.

* **Parameters:**
  **mode** (*int*) – the spin-less fermionic mode on which to act.
* **Returns:**
  A creation [`FermionAction`](qiskit_fermions.operators.fermion_action.FermionAction.html.md#qiskit_fermions.operators.fermion_action.FermionAction) on `mode`.
* **Return type:**
  tuple[bool, int]
