# ann

### ann(mode)

Constructs an annihilation action on the fermionic mode at `mode`.

* **Parameters:**
  **mode** ([*int*](https://docs.python.org/3/builtins/functions.html#int)) – the spin-less fermionic mode on which to act.
* **Returns:**
  An annihilation [`FermionAction`](qiskit_fermions.operators.fermion_action.FermionAction.html.md#qiskit_fermions.operators.fermion_action.FermionAction) on `mode`.
* **Return type:**
  [tuple](https://docs.python.org/3/builtins/stdtypes.html#tuple)[[bool](https://docs.python.org/3/builtins/functions.html#bool), [int](https://docs.python.org/3/builtins/functions.html#int)]
