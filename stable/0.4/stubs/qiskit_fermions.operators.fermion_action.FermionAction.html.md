# FermionAction

### FermionAction

A fermionic creation or annihilation action.

A 2-tuple `(action, mode)` where `action` is `True` for a creation and `False` for an
annihilation action, and `mode` is the spin-less fermionic mode index on which to act.

alias of [`tuple`](https://docs.python.org/3/builtins/stdtypes.html#tuple)[[`bool`](https://docs.python.org/3/builtins/functions.html#bool), [`int`](https://docs.python.org/3/builtins/functions.html#int)]
